# Vinyl Discs

Client-side Fabric mod for Minecraft 1.21.11.

## Features

- Replaces every vanilla music disc with a vinyl record appearance.
- A vinyl record is shown on top of a jukebox while a record is inserted.
- Records placed in item frames become small wall-mounted vinyl stands.
- Glow item frames automatically get an illuminated LED strip on the stand.
- No server-side mod is required.

## Build

Use Java 21 and Gradle/Loom, then run:

```bash
gradle build
```

The finished jar is in `build/libs/`.
